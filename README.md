# 월스트리트 시그널 (`stock_tycoon_server`)

1~35인이 라운드별 업종·테마·매출·실적·리스크 브리핑을 분석해 12개 가상 업종 주식을 매수/매도하고, 최종 총자산 수익률로 순위를 가리는 개인전 모의 주식 투자 웹 보드게임입니다.

## 주요 특징
- **지원 인원**: 1~35명 (혼자서도 플레이 가능, 개인전 최종 순위 및 수익률 공개)
- **상장 10개 업종**: 반도체(`SEMI`), 자동차(`AUTO`), 항공(`AIRL`), 금융(`FINC`), 소비재(`CONS`), 화장품(`COSM`), 석유화학(`CHEM`), 철강(`STEL`), 건설(`CNST`), 바이오(`BIOH`), 가상자산(`CRYP`), 에너지(`ENRG`)
- **대면 & 비대면 통합**:
  - `/` : 참가자 스마트폰 화면 (업종/테마 브리핑, 터치형 10종목 매수/매도 카드, 보유 포트폴리오 및 평단가/수익률, 전체 채팅, QR 초대)
  - `/host` : 빔프로젝터 전광판 (PIN 잠금, QR 코드 직결, 10종목 주가·등락률 보드, 라운드 브리핑, 중간/최종 랭킹, 한국어 TTS 안내)
- **보안 및 세션 유지**:
  - 관리자 PIN 인증 전용 (환경변수 `ADMIN_PIN` 설정 가능, 기본값 `20822`)
  - `localStorage` 고유 토큰 기반 세션 자동 복구
  - 게임 시작/초기화 시 `cleanupDeadSockets()`로 유령 소켓 일괄 정리

## Render.com 배포 방법
1. GitHub 저장소에 이 폴더의 파일들을 업로드합니다.
2. Render.com에서 **New Web Service**를 생성하고 저장소를 연결합니다.
3. **Build Command**: `npm install`
4. **Start Command**: `npm start`
5. (선택) **Environment Variables**에 `ADMIN_PIN`을 원하는 4자리 숫자로 설정합니다.
